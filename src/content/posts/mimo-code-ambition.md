## 先说结论

所有 AI Coding Agent 的终局都不是写代码。

**终局是：谁能用代码解决非代码的问题，谁就赢了。**

办公、数据、流程、企业数字化——这些场景的底层都是代码。谁有一个够强的 Coding 引擎，谁就能横扫所有需要逻辑执行的领域。

小米的 Mimo Code，加上金山的 WPS + 金山云，恰好走的是这条最短路径。

---

## 行业已经证明了

别猜，看数据：

- **微软 Copilot** 从 GitHub 扩到 Office、Dynamics、Power Platform。同一个 Coding 引擎，吃掉了开发者 + 办公 + 企业三个市场。
- **OpenAI Codex** 本质是把代码执行变成了通用任务执行的后端。你给它一个任务，它写代码、跑代码、返回结果。
- **Anthropic Claude Code** 从终端切入，用极致的 Coding 能力证明了一件事：当你能帮开发者解决最难的编程问题，你就能用同样的逻辑去解决任何领域的问题。
- **Cursor CEO** 原话：目标不只是服务开发者，而是"让每个人都能用自然语言驱动复杂任务"。

国内同样在加速。**腾讯 WorkBuddy**、**阿里钉钉**、**字节飞书**——中国三大办公平台不约而同押注 AI，都在做同一件事：**让 AI 深入工作流，不只是聊天，而是真正干活。**

**全球共识已经形成：办公平台的下一站是 AI Agent。**

**这不是猜测，这是已经在发生的事。**

Coding Agent 的能力边界，从来不是程序员的办公桌。它是一个通用的逻辑执行引擎——能操作 Excel，能编排流程，能调 API，能交付产品。

**会写代码的 AI，天然会做所有结构化的工作。**

## 小米的牌有多好

现在关键问题：**谁能最快把 Coding Agent 变成 Work Agent？**

你需要三样东西：
1. 强 Coding 引擎
2. 办公场景入口
3. B2B 行业积累

**小米三样全有。**

**Mimo Code** 是引擎——小米自研的 Coding Agent，能力对标一线。

**WPS** 是入口——5 亿月活，中国办公软件第一梯队。每一次用户打开 WPS，都是一个被 Coding Agent 接住的场景。

**金山云** 是行业积累——政务、金融、医疗、制造，深耕多年，有客户，有场景，有 know-how。

把这三样拼起来：

```
Mimo Code（引擎）
  + WPS（5亿用户入口）
  + 金山云（B2B垂直场景）
  = 中国版 Codex × Work
```

**这个组合，其他玩家要从零构建，小米已经全有了。**

## Mimo 的路线图

看清趋势的人会发现，这条路小米是一步一步在走的：

**第一步：Coding Agent（已落地）**——Mimo Code，先把引擎做到最强。

**第二步：接入 WPS（正在发生）**——把 Coding 能力注入中国最大的办公平台。自动写文档、自动做表、自动跑数据分析，这些不是未来，是马上。

**第三步：下沉到金山云的 B2B 场景（即将启动）**——政务、金融、医疗、制造，金山云已经有客户有场景，只差一个够强的 Coding 引擎。Mimo Code 就是那个引擎。

**第四步：Work Agent（终极形态）**——从办公到行业，从行业到全场景。小米的 IoT 生态、汽车、智能家居，都将成为 Coding Agent 的延伸触角。

回头看腾讯 WorkBuddy、阿里钉钉、字节飞书，它们也在走类似的路——但起点不同。它们从聊天协作起家，往上加 AI；小米从 Coding 引擎起家，往外扩场景。**引擎层的起点决定了天花板的高度。**

这条路，Mimo 每一步都会走到。

## 扩垂类的逻辑

别再想"AI Coding 只是帮程序员省时间"了。

真正的增长在垂类扩展：

- **办公自动化**：WPS + Mimo Code → 自动生成报表、处理数据、编排工作流
- **金融合规**：金山云 + Coding Agent → 自动生成合规报告、风险检测
- **医疗信息化**：电子病历自动化、影像报告辅助生成
- **政务数字化**：审批流程自动编排、数据互通

**每个垂类都是一个新市场。每个新市场底层都是同一个 Coding 引擎。**

这就是为什么 Coding Agent 的天花板远不止开发者——它的天花板是**所有需要结构化解决问题的人**。
